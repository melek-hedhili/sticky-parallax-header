# Native settings preserved during the SDK 57 migration

Recorded 2026-10-06 before regeneration. The previous projects were generated by
Expo SDK 45 (commit `014bc6a`); later native changes added the release scheme and
FlashList Pods. There are no custom application native modules.

| Setting | Existing value and treatment |
| --- | --- |
| iOS bundle identifier and URL scheme | `com.react-native-sticky-parallax-header-example`, retained |
| Android application ID and URL scheme | `com.reactnativestickyparallaxheaderexample`, retained |
| Name | `react-native-sticky-parallax-header-example`, retained |
| Native app version / build | `1.0.0` / `1`, retained |
| iOS tablet and orientation | Tablet enabled; portrait, upside-down portrait, both landscapes; no full-screen requirement, retained |
| Appearance | Light; default status bar; controller-based status bar appearance disabled on iOS, retained |
| iOS transport | Arbitrary loads enabled and localhost HTTP exception, retained |
| iOS entitlement | `aps-environment=development`, retained; no new push service added |
| Android | Backup and cleartext enabled; single-task activity and resize keyboard behavior, retained |
| Android permissions | Internet, external-storage read/write, system alert window, vibrate, retained |
| Android icons | Original density-specific launcher and round PNGs preserved in `native-assets/android` and copied by the local plugin |
| iOS icon | Original catalog had no image files; remains a template icon catalog |
| Splash | Original iOS background is a 1×1 white image; preserve white launch background through the splash plugin. Android uses an explicit transparent drawable so its background-only splash has a valid theme icon resource |
| Android theme | Original primary `#023c69` and primary-dark `#ffffff`; preserve where applicable under modern edge-to-edge rendering |
| Release scheme | Additional `reactnativestickyparallaxheaderexamplerelease` scheme with Release launch, generated from current target UUIDs |

The checked-in app never linked `expo-updates`: it is absent from package.json,
Yarn lockfile and Podfile.lock. iOS loaded Metro in Debug and embedded
`main.jsbundle` in Release. The obsolete SDK 45 update metadata pointing to
`https://exp.host/@mateusz.medrek/react-native-sticky-parallax-header-example`
is therefore removed; no EAS project, update module, or OTA service is introduced.

SDK 57 intentionally replaces old infrastructure: JSC with the SDK default Hermes,
the disabled legacy architecture with required New Architecture, Flipper and old
JNI/Java templates with current templates, iOS 12 with 16.4, and Android API 21
with 24 (compile/target API 36). Modern platform status-bar and edge-to-edge
behavior must be checked at runtime rather than assumed identical.

`app.json` and `plugins/withNativeSettings.js` are the reproducible inputs. Run
`yarn prebuild` in this directory only after reviewing changes to those inputs.
The command regenerates native projects; dependency installation and Pods are
separate setup operations. Both native directories remain tracked for review.

The installed `expo-splash-screen@57.0.9` writes a reference to
`@drawable/splashscreen_logo` even when only `backgroundColor` is configured, but
does not generate that resource. On 2026-10-06 this reproduced a
`:app:processDebugResources` failure. The plugin's Android `drawable.icon` points
to `native-assets/splashscreen_logo.xml`, a transparent layer that preserves the
white background and is copied into Android resources during prebuild. Keep both
the source asset and its checked-in generated resource. This avoids editing
dependencies or changing splash branding; see the
[upstream fix](https://github.com/expo/expo/pull/49371).
